# Security

Please don't report a security problem in a public issue or pull request.

Report it privately instead: on this repo's **Security** tab, choose
**Report a vulnerability**
([direct link](https://github.com/idevkore/dk-tunekore/security/advisories/new)).
Say what you found, how to reproduce it, and which version or commit you
tested. devKore will reply there.

tuneKore is in early development and has no supported releases yet, so fixes
land on `main`.
